# 📚 Sistema de Biblioteca com POO em Python

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![Paradigma](https://img.shields.io/badge/POO-Programação%20Orientada%20a%20Objetos-green)

Este projeto é um sistema simples de gerenciamento de biblioteca desenvolvido em **Python**, utilizando os conceitos de **Programação Orientada a Objetos (POO)**.

A aplicação funciona via terminal e permite o controle básico de livros e revistas.

---

## 🎯 Objetivo

Este projeto foi criado com o intuito de praticar:

- Estruturação de código com classes
- Uso de herança
- Organização de arquivos em um projeto
- Interação com o usuário via terminal

---

## ⚙️ Funcionalidades

O sistema possui as seguintes funcionalidades:

- 📖 Cadastro de livros  
- 📰 Cadastro de revistas  
- 📋 Listagem de todos os itens cadastrados  
- 📦 Empréstimo de itens por código  
- 🔄 Devolução de itens por código  
- ⚠️ Validação de entradas inválidas  

---

## 🧠 Conceitos aplicados

Neste projeto foram utilizados conceitos importantes de POO:

- **Encapsulamento** → organização dos dados dentro das classes  
- **Herança** → classes específicas reutilizando uma classe base  
- **Abstração** → simplificação das operações do sistema  
- **Polimorfismo** → comportamentos diferentes dependendo do objeto
